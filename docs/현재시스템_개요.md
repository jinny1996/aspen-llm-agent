# 현재 시스템 개요

작성: 2026-10-08 / 기준 코드: `2609 수정/phase13`

## 1. 한 줄 요약

논문(텍스트+그림)을 입력하면 Aspen Plus 모델 파일을 만들어 주는 Gradio 챗봇 시스템. 기반 파이프라인(Part1~3)은 완성·실전 검증되었고, 그 위에 "논문에 없는 값을 근거와 함께 기록하고 필요하면 사람에게 묻는" EDC 기능이 플래그로 얹혀 있다. EDC 평가는 논문 3편 수준의 파일럿 단계다.

## 2. 기반 파이프라인 (완성)

| 층 | 역할 |
|---|---|
| Part1 | 논문·그림에서 공정 스키마(YAML) 생성, 값마다 근거 인용 부착. 스키마가 불완전하면 보완 단계 |
| Part2 | 스키마 → Aspen COM 코드. 4단계 검증기(물성 방법, 연결, 피드, 블록 사양) + 자동 복구 |
| Part3 | Aspen 실행 → `.his` 로그 파싱 → RAG 진단 → 패치 계획/코드 생성 → 재실행 |
| 인프라 | 고정 그래프 대신 `bind_tools` 에이전트 루프, 세 파트 모두 MCP 서버 경유, Gradio 챗봇(`app.py`, 실시간 스트리밍), 사용자 개입은 챗봇 턴 단위 |

진행 이력: Phase 0~F 종결. 4~6월 GPT 반복 실험 자료(성공률, 토큰·시간 CSV)와 학회용 그림이 별도로 있다.

## 3. EDC (Evidence-grounded DoF Closure) — phase13

| 기능 | 플래그 | 내용 |
|---|---|---|
| 자유도 장부 | 항상 | 블록별 규칙으로 필요한 값이 다 있는지, 인용문이 논문에 있는지 검사 (`dof_ledger.py`) |
| 근거 분류 + 질문 선택 | `PART1_EDC_POLICY=1` | STATED / SWEPT / BORROWED_SUSPECT / ASSUMED / ALTERNATIVE 등으로 분류, 영향도 기준 상한 5개 질문 (`edc_policy.py`, LLM 무호출) |
| 답변 반영 | 〃 | `ID=값` 답변을 스키마에 반영, 원본 백업, 범위 밖 값은 경고만 하고 수용, 인식 실패 시 1회 재질문 |
| 프롬프트 보강 | `PART1_EDC_PROMPT=1` | 인용 원문, 후보 값 목록, 인용 범위, 계산식, 조성 근거, 물성 방법 대체 기록 (`edc_prompt.py` v2) |
| 가정 요약 | `PART1_EDC_POLICY=1` | 챗봇 끝에 "직접 바꾼 값 / 질문에서 확인한 값 / 묻지 않고 가정한 값 / 물성 방법" 출력 |
| 보완 후 검토 | 〃 | 보완 단계를 거친 `Schema_validated.yaml`에 대해서도 질문 |
| 블록 ID 정규화 | 항상 | 4글자 초과 ID를 `B<n>`으로 (MHeatX 5글자 실패 대응) |
| Part2 수정 | 항상 | 성분 ID 매핑 오류, 질량 기준 유량 단위 오류, Aspen 입력 단위 읽기 확인 |
| 공용 파일 수정 | 항상 | `2608 수정/aspen_code_v1.py` 질량 유량 단위 수정 (백업 `.bak_before_massfix_20261008`) |
| 실행 도구 | | `run_case.py A/B/C [--part1-only] [--auto-ok] [--reply "ID=값; …"]`, `run_2e_batch.ps1`, `analyze_2e.py`, `score_2e.py` |

플래그를 모두 끄면 기존 동작과 같다(프롬프트 동일성 테스트 확인). 블록 ID 정규화·Part2 수정·공용 파일 수정은 항상 적용.

## 5. 실험으로 알게 된 것 (A, C 각 3~4회, 켜짐/꺼짐)

- 인용문 검증 통과율: 꺼짐 0.92~0.97 → 켜짐(v2) 1.00
- 분류 안정성: 뚜렷한 개선 없음 (잡음 수준)
- 켜야만 얻는 정보: 후보 값 포착, 조성 근거, 물성 방법 대체 기록
- 질문 수: 꺼짐 2개 → 켜짐 5개(상한)
- 케이스 B를 SI와 대조: 반응기 온도(예열 400 °C를 옮겨 씀, 실제 425)와 압력 오류를 질문으로 포착
- C의 정밀도/재현율 1.00/1.00은 C를 보고 만든 규칙이라 성과로 쓸 수 없음 (in-sample)

## 6. 알려진 한계

- 정답 라벨은 C 10개뿐. 논문 3편, 반복 3~4회. 일반화 주장 불가
- 최근 규칙 다수가 B·C 결과를 보고 만들어짐 → 새 논문으로 재측정 필요
- 모델이 인용문을 쓰지 않으면 "다른 구성에서 가져온 값"을 구분 못 함 (예: 330 °C)
- 영향도 표(HIGH/MED/LOW)와 질문 상한 K=5는 임시값, 화학공학 검토 전
- 반응기는 RGIBBS만 지원. 증류탑(RADFRAC)은 분석 규칙만 있고 Part2 미지원 (추후 지원 예정)
- B의 MHeatX CROSSOVER 경고는 반응기 온도 수정으로도 사라지지 않았고 원인 미확인
- 영향받은 과거 실행 63개(질량 유량 오류)는 필요한 것만 재실행 예정 (`영향받은_과거_실행_목록_질량유량오류.md`)
